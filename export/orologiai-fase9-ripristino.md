# Ripristino del checkpoint parziale

Scaricare tutti i file del checkpoint fuori dall'ambiente Freebuff. Verificare gli hash con `sha256sum -c orologiai-fase9-20261027.sha256` nella directory che li contiene. Il bundle Git contiene la storia fino al commit `7ccd3982688f3e86f774166f617183276ffd194d`; si può ricostruire una copia con `git clone orologiai-fase9-20261027.bundle orologiai-ripristinato` e `cd orologiai-ripristinato`. Lo ZIP contiene i file tracciati del commit, senza segreti, dipendenze o file non tracciati; il database è esportato anche separatamente. Eseguire `npm ci` e `npm run verify`. Prima di qualsiasi pubblicazione riconfrontare la produzione Cloudflare e preservare gli aggiornamenti esterni: il deployment `37d5879f-7654-482b-91f7-42960177d20f` è l'ultimo osservato durante questa sessione, non una garanzia per il futuro.
